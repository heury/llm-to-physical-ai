# MiniMind-J Implementation Plan

> 과거 v1 설계 기록. 현재 구현은 `2026-10-20-parallel-questions.md`의 v2 구조로 교체했습니다.

**Goal:** MiniMind 기반의 작고 독립적으로 실행 가능한 교육용 선택 모델.

**Architecture:** 각 (입력, 후보) 쌍을 같은 causal MiniMind로 인코딩하고 마지막 EOS의 hidden state를 공유 MLP로 채점한다. 후보 차원을 복원해 padding을 마스킹하고 cross entropy로 학습한다. 원본 CLEF의 joint schema head를 재현하지 않는 의도적인 단순화다.

**Tech Stack:** Python, PyTorch, Transformers, pytest.

1. `tests/test_decision.py`: 후보 마스킹, 순열 등가성, padding 불변성, 학습, 저장/복원, LM 변환, 잘못된 데이터 테스트를 먼저 작성하고 실패 확인.
2. `model/model_minimind.py`: 로컬 MiniMind의 config/backbone을 독립 복사. 기존 파일은 수정하지 않는다.
3. `model/decision.py`, `dataset.py`: 공유 점수 head, JSONL 검증, pair collator, byte/HF tokenizer, strict LM 변환과 checkpoint 구현.
4. `train.py`, `decide.py`, `data/*.jsonl`: CPU 기본 학습과 JSON 추론, 작은 한국어 예제.
5. `README.md`, `NOTICE`, `LICENSE`: 수식, 코드 읽기 순서, 원본과의 차이, 실행법, pretrained 변환 제한 설명.
6. CPU pytest 및 실제 CLI 학습→저장→추론 실행. 결과를 `docs/verification.md`에 기록.

검증 명령: `python -m pytest -q`, `python train.py --epochs 30 --output /tmp/minimind-j-smoke`, `python decide.py --checkpoint /tmp/minimind-j-smoke --input '배송이 언제 오나요?' --choices '배송 문의' '환불 요청'`.

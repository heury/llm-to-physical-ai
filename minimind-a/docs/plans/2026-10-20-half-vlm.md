# Half-depth VLM implementation plan

**Goal:** New MiniMind-A training uses the first half of MiniMind-V language layers.

**Architecture:** Keep `vlm_config.num_hidden_layers` as the source depth. Construct
only `max(1, source_depth // 2)` layers; load the retained prefix from native VLM
weights and skip only known discarded-layer keys. Keep SigLIP, hidden width,
final norm and action expert unchanged. VLA checkpoint format 2 requires fresh
training; no legacy migration and no deletion of historical artifacts.

**Tech stack:** PyTorch, native MiniMind-V, pytest.

1. Add failing tests in `tests/test_vla.py`: depth, prefix hidden equivalence,
   gradients, native loading validation, compact checkpoint roundtrip and old-format rejection.
2. Implement in `model/model_vla.py`; run targeted tests.
3. Exercise half-depth one-epoch training via `tests/test_train.py`.
4. Report source/used layers in `train_vla.py`; distinguish cached contexts by
   depth in `scripts/runpod_so101/run.py`.
5. Update README and historical verification caveat; run full pytest and compile checks.

User explicitly accepts retraining and does not require old VLA checkpoint compatibility.
No paid training is part of this code change.
